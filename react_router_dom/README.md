# React Router App

A simple React website with Home, About and Contact pages, a navbar, and one CSS file.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Files

- `src/App.jsx` - routes
- `src/components/Navbar.jsx` - navbar
- `src/pages/` - Home, About, Contact
- `src/style.css` - all styles
